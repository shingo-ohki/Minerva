# [安住 淳](/shu/miyagi/4/azumi-jun)

立憲民主党

✅ [健康保険証とマイ保険証の併用を可能にします。](現行の健康保険証とマイナ保険証の併用を可能にします。)  
✅ [解雇規制の緩和に反対します。](働く人の解雇規制の緩和に反対です。)  
✅ [再生可能エネルギーを拡大します。](再生可能エネルギーの拡大を目指します。)  
✅ [高等学校までの授業料の無償化を目指します。](生まれた場所や親の生活水準による格差を無くすため、高等学校までの授業料の無償化と大学の授業料の大幅な負担軽減を目指します。)  
✅ [人口 減少 に 歯止め を ! 人口 減少 による 人手 不足 解消 の ため 、 積極 的 な 外国 人 の 受け入れ を 進め 、 定住 し やすい 環境 を つくり ます 。](人口 減少 に 歯止め を ! 人口 減少 による 人手 不足 解消 の ため 、 積極 的 な 外国 人 の 受け入れ を 進め 、 定住 し やすい 環境 を つくり ます 。)  
✅ [現行 の 健康 保険 証 と マイナ 保険 証 の 併用 を 可能 に し ます 政府 は 現在 、 マイ ナンバーカード と 一体化 し た マイナ 保険 証 の 普及 を 進め て い ます が 、 情報 の 流出 など の 懸念 が ある ため 、 現行 の 健康 保険 証 と の 併用 を 可能 に し ます 。](現行 の 健康 保険 証 と マイナ 保険 証 の 併用 を 可能 に し ます 政府 は 現在 、 マイ ナンバーカード と 一体化 し た マイナ 保険 証 の 普及 を 進め て い ます が 、 情報 の 流出 など の 懸念 が ある ため 、 現行 の 健康 保険 証 と の 併用 を 可能 に し ます 。)  
✅ [働く人 の 解雇 規制 の 緩和 に 反対 です 働く人 が それぞれ の 会社 で 都合 よく 解雇 さ れ やすい 緩和 に は 、 強く 反対 し ます 。 働く人 が 安心 し て 働ける 社会 を 目指し ます 。](働く人 の 解雇 規制 の 緩和 に 反対 です 働く人 が それぞれ の 会社 で 都合 よく 解雇 さ れ やすい 緩和 に は 、 強く 反対 し ます 。 働く人 が 安心 し て 働ける 社会 を 目指し ます 。)  
✅ [再生 可能 エネルギー の 拡大 を 目指し ます エネルギー 供給 に 占める 原子力 発電 の 依存 度 を 早い スピード で 低減 し 、 再生 可能 エネルギー の シェア を 高め て いき ます 。](再生 可能 エネルギー の 拡大 を 目指し ます エネルギー 供給 に 占める 原子力 発電 の 依存 度 を 早い スピード で 低減 し 、 再生 可能 エネルギー の シェア を 高め て いき ます 。)
