# [いなとみ 修二](/shu/fukuoka/2/inatomi-shuji)

立憲民主党

✅ [国民負担の見直しと最適化を進める。](国民 負担 の 見直し ( 見える化 → 最適 化 ))  
✅ [平和と主権を守り抜く外交・防衛を実施する。](日本 の 外交 ・ 防衛 は 日 米 同盟 が 基軸)  
✅ [増税はしない方針を掲げる。](増税 し ない)  
✅ [後世 に つなぐ 「 素晴らしい 日本 」 悠久 の 歴史 と 文化 を 持つ 日本 は 、 世界 に も 稀 な 素晴らしい 国 です 。](後世 に つなぐ 「 素晴らしい 日本 」 悠久 の 歴史 と 文化 を 持つ 日本 は 、 世界 に も 稀 な 素晴らしい 国 です 。)  
✅ [国民 負担 の 見直し ( 見える化 → 最適 化 ) 税金 や 社会 保険 料 負担 が 重く なり 、 高 所得 の 方 も 低 所得 の 方 も 大きな 痛み や 不満 を 感じ て い ます 。](国民 負担 の 見直し ( 見える化 → 最適 化 ) 税金 や 社会 保険 料 負担 が 重く なり 、 高 所得 の 方 も 低 所得 の 方 も 大きな 痛み や 不満 を 感じ て い ます 。)  
✅ [裏金 政治 を 終わらせる 。](裏金 政治 を 終わらせる 。)  
✅ [増税 し ない 。](増税 し ない 。)  
✅ [教育 の 機会 均等 を 取り戻す 。](教育 の 機会 均等 を 取り戻す 。)
